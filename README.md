# 📚 Plano de Estudos - FAB (CESD / CFC)

Plataforma web de estudos focada em concursos e processos internos da Força Aérea Brasileira (inicialmente voltada para o **CESD** e expansível para o **CFC**).

O projeto conta com organização de apostilas em PDF, simulados dinâmicos e auxílio de Inteligência Artificial para tirar dúvidas e gerar questões.

---

## 🚀 Tecnologias Utilizadas

- **Framework:** [Next.js](https://nextjs.org/) (App Router & TypeScript)
- **Estilização:** [Tailwind CSS](https://tailwindcss.com/) & [Lucide Icons](https://lucide.dev/)
- **Banco de Dados & Auth:** [Supabase](https://supabase.com/) (PostgreSQL & Storage)
- **Inteligência Artificial:** [Google Gemini API](https://aistudio.google.com/)
- **Deploy:** [Vercel](https://vercel.com/)
